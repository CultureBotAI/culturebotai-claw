# Minimal curation contract distribution

This distribution packages exact canonical CLAW source bytes from one pinned Git
commit. It is generated by `scripts/adhoc/stage_curation_distribution_20261107.py`;
the staging manifest records every file hash and the source commit. The canonical
sources remain under CLAW's `src/`; there is no separately maintained contract fork.

The base installation supports `kg_microbe_curation.identity`, `.artifact` and
`.native`, with only JSON Schema dependencies. It does not require orchestration,
LinkML, ontology tooling, providers or fleet configuration. Native adapters with
older LinkML constraints can install this base package without upgrading LinkML.

Install the `reviews` extra to use canonical `.contract` and `.ledger` validation.
That extra preserves CLAW's supported LinkML 1.10 family; it is intentionally not
compatible with a consumer that requires LinkML below 1.10. Packaging the base
native transport does not promise a review-runtime migration for that consumer.

The included review/governance support modules are the exact import closure of
the canonical review validator. This distribution does not expose the governance
synchronizer, fleet audit, orchestration CLI or their complete runtime resources.
There are no console scripts. Install it in an environment without
`kg-microbe-orchestration`: both distributions provide overlapping Python modules,
and pip does not enforce that exclusivity. Verify installed provenance and imported
file hashes before using an environment. Installing or validating these contracts
does not grant scientific approval or publication authority.

No package index release is performed by the staging/build workflow. Consumers
can install the resulting immutable wheel by path and retain its digest; registry
publication and permanent dependency adoption require their own review.
