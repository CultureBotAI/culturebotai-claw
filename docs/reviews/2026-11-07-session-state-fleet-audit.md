Issue: [Claw #938](https://github.com/CultureBotAI/culturebotai-claw/issues/938). Audit date: 2026-11-07.

This read-only audit pins each manifest Mech to the published main commit below. It changes no Mech, workflow, branch, session or temporary file. It informs the separately approved rollout; preparing Claw's policy does not install it downstream.

## Coverage and limits

The roster comes from `kg_microbe_fleet.load_fleet_manifest()`. Hidden tracked instruction trees are included, independently of gitignore rules: native skills/commands and agent guidance, workflow profiles, root prose, documentation, and named README/AGENTS/CLAUDE/SKILL entry points. Scientific review/research corpora are not treated as operating policy; their captured README/provenance matches are classified separately. Ignored or untracked local settings, global user instructions, live sessions and temporary directories were not inspected.

GitHub's recursive tree truncation was detected and expanded through complete subtrees. TaxonMech also has a scientific corpus tree too large for the non-recursive API. Its root and all instruction/documentation/workflow subtrees were enumerated completely; `curation`, `data`, `history`, `pages`, `reports` and `reviews` corpus roots were excluded. No whole-repository completeness claim is made for TaxonMech. The other thirteen tree inventories are complete. Every fetched text blob was checked against its Git object ID.

## Scratch output and retained history are separate

The audit does not classify every temporary-path mention as a campaign-state defect. Reproducible site previews/browser-test output, ROBOT conversion intermediates, immediate seeder staging, and command exit-status examples are disposable scratch. Validation logs and analysis output need an adoption-time retention decision: if they support a recorded review or closure, put them in the durable work root and retain the required evidence; if truly regenerable scratch, temporary storage remains permitted.

Historical or replay references were retained without rewriting their provenance. Examples include DUFMech's causal-graph campaign/provenance narratives, CMMMech's pilot-session history, and captured research/review README files. They do not establish the current location or safety of any live session.

The evidence census contains 480 matching lines across 157 files. Context classification counts (lines, not unique instructions): `caution` 2; `diagnostic_retention_review` 42; `disposable_scratch` 26; `historical_or_replay` 248; `session_state` 162. The private audit bundle retains every path, line, exact blob ID, context and classification, plus all workflow event maps and the fetching helper. These counts describe the stated documentation scope, not the excluded scientific corpus.

## Rollout disposition

Claw's canonical policy and regression guard can be changed in #938. Downstream replacement of these examples, existing session migration, backing up or publishing old branches, and live monitor deployment remain separate approval steps. This audit did not refresh timestamps, push branches, fetch into Mech checkouts or type into sessions.
